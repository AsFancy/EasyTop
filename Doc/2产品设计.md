## 0. 设计目标

- PD-0.1 桌面优先，非必要不打扰。
- PD-0.2 信息一屏可读，操作路径尽量短。
- PD-0.3 主页固定，其余页面在同一面板内切换，不打开独立窗口。
- PD-0.4 任何交互设计不得突破需求分析第 3 章的硬约束（焦点、穿透范围、不弹通知、单实例）。

---

## 1. 信息架构与导航

- PD-1.1 页面共四个：主页、日历、任务、设置。
- PD-1.2 页面导航位于顶部控制栏左侧；点击后在同一面板内切换内容区，不改变面板位置与尺寸。
- PD-1.3 启动后固定进入主页，不提供默认页配置。
- PD-1.4 页面切换后保留各页的筛选与滚动状态（当前会话内有效）。
- PD-1.5 托盘菜单可直接跳转到指定页面（见 7）。
- PD-1.6 导航形式（左侧栏 / 顶部标签）待定，见 10。

## 2. 全局状态与切换

### 2.1 状态总表

| 状态 | 进入方式 | 退出方式 | 界面表现 |
| --- | --- | --- | --- |
| 桌面模式（默认） | 启动 / 收起置顶 / 取消钉住 | 快捷键置顶、钉住、锁定、隐藏、退出 | 位于桌面层，被普通窗口覆盖 |
| 置顶模式 | 全局快捷键 | 再次按快捷键 / Esc | 升至最顶层、可交互、带视觉提示 |
| 钉住模式 | 顶部控制栏“钉住” | 顶部控制栏“钉住” | 面板主体穿透，控制栏可点 |
| 隐藏 | 托盘菜单“隐藏” | 托盘菜单“显示” | 桌面层不显示，托盘图标仍在 |
| 锁定 | 顶部控制栏“锁定” / 系统锁屏 | 输入正确密码 | 内容整体遮蔽 |
| 退出 | 顶部控制栏“关闭” / 托盘菜单“退出” | — | 进程结束，后台能力停止 |

### 2.2 桌面模式

- PD-2.2.1 未被其他窗口覆盖时，挂件是普通可交互窗口：点击、拖拽、双击启动、文本输入均正常，不存在点击穿透或区域不可点。
- PD-2.2.2 点击挂件即激活窗口（需求 3.1.5），当前应用转为非激活但不最小化。
- PD-2.2.3 被动刷新不改变前台应用焦点。

### 2.3 置顶模式

- PD-2.3.1 全局快捷键唤出时升至最顶层并可直接交互。
- PD-2.3.2 再次按同一快捷键或按 Esc 收起，回到进入前的桌面模式。
- PD-2.3.3 点击面板外部不自动收起，仅快捷键或 Esc 收起，避免编辑时误触。
- PD-2.3.4 收起时尽量把焦点还给切换前的应用；原应用已退出则不强制。
- PD-2.3.5 快捷键注册失败时提示冲突，并引导进入设置修改。
- PD-2.3.6 置顶与桌面模式需有可感知的状态差异（视觉见 3 UI 设计）。

### 2.4 钉住模式

- PD-2.4.1 钉住后，面板主体（除控制栏以外的区域）鼠标穿透：点击、滚轮、拖拽均落到下层桌面；下层是桌面图标时按系统正常行为选中。
- PD-2.4.2 面板主体仍持续刷新数据（时间、任务状态、倒计时），只是不接受输入。
- PD-2.4.3 顶部控制栏保持可点，可取消钉住、锁定或关闭；点击控制栏可激活窗口。
- PD-2.4.4 钉住状态可跨重启保持，启动后直接进入钉住模式。
- PD-2.4.5 钉住与置顶互斥：按全局快捷键进入置顶模式时自动解除钉住；置顶时点击“钉住”，先回到桌面模式再进入钉住。
- PD-2.4.6 钉住时鼠标悬停不出现任何反馈（视觉见 3）。
- PD-2.4.7 钉住状态下面板位置锁定，不能从主体拖动；需要移动时先取消钉住。
- PD-2.4.8 界面需清晰表达“只有顶部可点”（视觉手段见 3）。

### 2.5 锁定状态

- PD-2.5.1 锁定后，面板内容整体遮蔽，遮罩上仅显示锁图标与“点击解锁”；任务标题、启动项名称等文字不可辨认。
- PD-2.5.2 锁定后不可查看、不可操作任何页面内容，包括页面切换、任务编辑、启动项启动与拖拽。
- PD-2.5.3 点击遮罩进入密码输入；连续输错 5 次后进入等待，界面显示剩余等待时间。
- PD-2.5.4 顶部控制栏在锁定状态下仅保留“解锁”入口；关闭与钉住按钮是否保留待定（10）。
- PD-2.5.5 未设置密码时点击“锁定”，先引导设置密码，不直接进入锁定。
- PD-2.5.6 锁定状态下托盘菜单仍可打开，但仅“显示/隐藏”“退出”“解锁”可用（见 7.2）。
- PD-2.5.7 锁定状态下若处于置顶模式是否自动解除置顶，待定（10）。
- PD-2.5.8 解锁后按当前时间重新计算任务状态并刷新展示。
- PD-2.5.9 忘记密码入口指向重置流程：二次确认并明确清空全部数据、不可撤销。
- PD-2.5.10 锁定状态跨重启保持，启动后直接呈现遮罩。

### 2.6 顶部控制栏

- PD-2.6.1 布局：左侧为页面导航，右侧为三个控制按钮，从左到右为关闭、钉住、锁定。
- PD-2.6.2 三个按钮均有悬停提示，提示文案随当前状态变化（如“钉住：仅显示不可操作” / “取消钉住”）。
- PD-2.6.3 关闭：直接退出程序并结束进程，不弹常规确认框；仅当存在未保存的编辑内容时才提示确认。
- PD-2.6.4 钉住：切换面板主体的鼠标穿透状态，按钮图标同步切换为“已钉住”。
- PD-2.6.5 锁定：立即进入锁定状态；未设置密码时先引导设置。
- PD-2.6.6 控制栏在桌面、置顶、钉住、锁定状态下都必须可点击，不得被透明层或穿透区域覆盖。
- PD-2.6.7 控制栏同时作为窗口拖动区（钉住状态与锁定状态除外），拖动仅在免于穿透的区域内生效。
- PD-2.6.8 按钮顺序与图标以 3 UI 设计为准。

### 2.7 面板移动与尺寸

- PD-2.7.1 通过控制栏拖动面板；位置按显示器记忆，重启后恢复。
- PD-2.7.2 同一时间只显示一份挂件，可拖动到任意显示器。
- PD-2.7.3 显示器增减、分辨率或 DPI 变化后，位置自动校正到可见区域内。
- PD-2.7.4 面板固定为完整圆角矩形，不自动隐藏、不吸附边缘、不做 Dock 式收起。
- PD-2.7.5 尺寸调整的入口与档位待定（10）。

## 3. 主页

### 3.1 区域构成

主页固定由上下两部分组成，不提供修改：

- 今日信息卡（上部）：日期与假期信息、待办摘要、临期区。
- 快捷启动台（下部）：分组与启动项。

### 3.2 今日信息卡

- PD-3.2.1 日期区：公历日期与星期、农历日期（可含干支与生肖）、当日节气与传统节日。
- PD-3.2.2 假期区：距离周末天数与周末日期、调休上班日提示、下一个法定节假日名称与倒计时；今日为节假日或调休上班日时明确标识。
- PD-3.2.3 摘要区：今日待办数、临期数、已延期数三个数字；点击任一数字进入任务页并应用对应筛选。
- PD-3.2.4 节假日数据未覆盖当前年份时，在日期区就地显示明确提示，不使用占位或推算数据。

### 3.3 临期区

- PD-3.3.1 固定在今日信息卡内，常驻显示；无相关内容时展示空状态文案，不隐藏区域。
- PD-3.3.2 排序：已延期在前、即将到期在后；同级内按优先级、截止时间排序。
- PD-3.3.3 每条显示标题、截止时间与状态标记；已延期任务直接显示逾期天数。
- PD-3.3.4 数量超出可视范围时区域内部滚动，不挤压上方日期与倒计时信息。
- PD-3.3.5 点击任务进入任务页并定位到该任务详情。
- PD-3.3.6 锁定状态下随面板一起遮蔽，不提供任何外部提示。

### 3.4 快捷启动台

- PD-3.4.1 添加入口：从资源管理器或桌面拖入程序、文件、文件夹；网址通过“新建网址”对话框添加。
- PD-3.4.2 拖入后立即在数据目录生成 `.lnk` / `.url` 并出现在当前定位的分组中；原目标不复制、不移动。
- PD-3.4.3 拖入的是快捷方式时，解析其目标后重新生成，提示已转换。
- PD-3.4.4 自动读取名称与图标；名称可重命名。网址用域名首字母生成图标，不联网抓取。
- PD-3.4.5 分组：支持新建、重命名、排序、删除；条目可拖拽跨组移动。分组的呈现形式（标签页 / 分区）待定（10）。
- PD-3.4.6 条目支持拖拽排序、重命名、删除；删除仅移除条目，不删除源文件。
- PD-3.4.7 启动方式按设置执行（单击或双击，默认双击）；仅“以管理员身份运行”对程序条目可用，并会触发 UAC。
- PD-3.4.8 启动失败时给出明确提示，保留条目不做自动移除。
- PD-3.4.9 目标不存在时条目标记为“失效”，提供重新定位与移除入口。
- PD-3.4.10 右键菜单：打开、打开文件位置、以管理员身份运行（仅程序）、重命名、更换图标、移除。
- PD-3.4.11 搜索框按名称过滤当前视图；条目过多时组内滚动或翻页，形式待定（10）。
- PD-3.4.12 布局项（图标尺寸、是否显示名称、行列数）可配置，可配置范围待定（10）。
- PD-3.4.13 空状态：无条目时展示拖入引导与“新建网址”入口。
- PD-3.4.14 不对系统桌面图标做任何扫描、隐藏或移动。

## 4. 日历

### 4.1 月视图

- PD-4.1.1 7 列月历；顶部提供上一月、下一月、回到今天。
- PD-4.1.2 每格显示：公历日、农历日、今日高亮、周末 / 节假日 / 调休标识。
- PD-4.1.3 每格显示当日任务摘要：最多 N 条（按优先级与时间排序）加“还有 n 项”；N 待定（10）。
- PD-4.1.4 点击日期空白处快速新建任务；点击任务条目打开任务详情。
- PD-4.1.5 拖拽任务到其他日期完成改期，时间字段保持不变。
- PD-4.1.6 上月/下月补位日期弱化显示；是否允许点击跳转待定（10）。

### 4.2 周视图

- PD-4.2.1 7 天周视图；顶部提供上一周、下一周、回到本周。
- PD-4.2.2 显示全天任务与定时任务；定时任务展示开始–结束时间。
- PD-4.2.3 新建、编辑、拖拽改期的操作与月视图一致。
- PD-4.2.4 周起始日按设置执行（周一或周日，默认周一）。
- PD-4.2.5 是否提供小时时间轴待定（10）；当前按 7 列日卡设计。

### 4.3 新建与编辑任务

- PD-4.3.1 编辑表单字段顺序：标题 → 日期 → 开始/结束时间 → 手动状态 → 优先级 → 类别 → 备注。
- PD-4.3.2 新建默认值：日期为当天、手动状态为未开始、优先级为中，时间与类别留空。
- PD-4.3.3 快速新建只暴露标题与优先级，提交后其余字段取默认值。
- PD-4.3.4 定时任务的结束时间必须晚于开始时间；校验失败就地提示，已填内容不丢失。
- PD-4.3.5 类别为自由文本，输入时提供已有类别建议，也允许直接输入新值。
- PD-4.3.6 保存成功后日历、任务页与临期区同步刷新。
- PD-4.3.7 删除任务需确认，确认文案说明不可恢复。
- PD-4.3.8 关闭编辑界面时若有未保存内容，提示是否放弃。

### 4.4 空状态

- PD-4.4.1 当前周期无任务时，在视图内展示引导文案与新建入口，不移除日历网格本身。

## 5. 任务页

### 5.1 分区视图

- PD-5.1.1 两种分区模式：按状态（默认）、按类别；记住上次选择。
- PD-5.1.2 按状态分区时，分区顺序固定为：已延期、即将到期、进行中、未开始、已完成。
- PD-5.1.3 已完成分区默认折叠，可通过分区标题展开。
- PD-5.1.4 按类别分区时，未填写类别的任务归入“未分类”，固定排在最后；其他类别按名称排序。
- PD-5.1.5 每个分区标题旁显示任务数量。

### 5.2 排序

- PD-5.2.1 分区内按优先级、截止时间、创建时间排序，口径见需求 5.3。

### 5.3 筛选与搜索

- PD-5.3.1 快捷筛选：今天、本周、即将到期、已延期、已完成。
- PD-5.3.2 组合筛选：状态、优先级、日期范围、类别、关键词，可叠加使用。
- PD-5.3.3 关键词匹配标题、备注与类别。
- PD-5.3.4 从主页摘要数字或临期区任务跳转时，自动应用对应筛选并定位目标。
- PD-5.3.5 清空筛选后回到默认分区视图。

### 5.4 行内操作

- PD-5.4.1 可直接修改手动状态，也可一键标记完成 / 取消完成；完成时记录完成时间。
- PD-5.4.2 支持编辑、改期、删除；删除需确认。
- PD-5.4.3 系统状态命中时展示系统状态，并在状态旁标注原因（如“因到期自动变更”），改期后恢复显示手动状态。
- PD-5.4.4 已完成任务不参与临期与逾期判定，也不进入临期区。

### 5.5 空状态

- PD-5.5.1 无任务时展示引导文案与新建入口；筛选无结果时提示“无匹配任务”并提供清空筛选入口。

## 6. 设置页

- PD-6.1 分组顺序：外观、行为、启动、日历、安全、数据、关于。
- PD-6.2 外观组：不透明度、背景模糊开关与强度、主题、面板尺寸与位置。
- PD-6.3 行为组：全局快捷键、全屏自动隐藏、单击/双击启动、显示器选择。
- PD-6.4 启动组：开机自启开关。
- PD-6.5 日历组：周起始日、农历/节气显示、临期阈值（1 小时–30 天，默认 72 小时）。
- PD-6.6 安全组：设置/修改锁定密码、系统锁屏自动锁定开关、清除密码、重置数据。
- PD-6.7 数据组：打开数据目录、清空数据。
- PD-6.8 关于组：版本号、许可信息；检查更新待定（见需求 4.5.7 与第 8 章）。
- PD-6.9 危险操作（清除密码、重置数据、清空数据）均需二次确认，并明确不可撤销与影响范围。
- PD-6.10 设置项保存后即时生效；确实需要重启的项，在改动时就地提示需要重启。

## 7. 托盘

- PD-7.1 托盘菜单项与顺序：显示/隐藏、主页、日历、任务、设置、开机自启开关、退出。
- PD-7.2 锁定状态下托盘菜单仍可打开，但仅“显示/隐藏”“退出”“解锁”可用，其余入口置灰不可点。
- PD-7.3 托盘“退出”与顶部“关闭”行为一致：直接退出；仅存在未保存编辑时确认；退出后无残留进程。
- PD-7.4 双击托盘图标执行显示/隐藏切换。

---

## 8. 首次引导

- PD-8.1 首次启动提供 3 步以内的引导：添加第一个启动项、创建第一个任务、设置全局快捷键。
- PD-8.2 引导在主页面板内完成，不打开独立窗口。
- PD-8.3 可跳过引导；跳过不阻塞后续使用。

## 9. 交互一致性约定

- PD-9.1 空状态：临期区常驻且显示空状态；启动台、任务页、日历显示引导与主操作入口。
- PD-9.2 错误与校验：就地提示，保留用户已填内容；数据问题给出可读说明，不崩溃、不静默覆盖。
- PD-9.3 确认：仅删除、清空、重置、清除密码、存在未保存编辑时退出这几类操作弹确认；常规操作不打断。
- PD-9.4 悬停：所有可交互元素有悬停提示，提示文案反映当前状态而非固定文本。
- PD-9.5 键盘：Esc 收起置顶；主要操作可键盘完成；密码输入支持回车提交。
- PD-9.6 静默：状态变化不弹窗、不闪烁、不发系统通知；钉住态主体无悬停反馈。
- PD-9.7 数据一致：任务或设置保存后，所有呈现同一数据的位置同步刷新。
- PD-9.8 不可逆提示：删除、清空、重置的确认文案必须写明后果，不使用仅“是否继续”的模糊措辞。

## 10. 设计待定项

1. 面板尺寸：固定档位还是自由拖拽（含最小/最大限制）？
2. 启动项是否需要支持自定义图标？（需求 4.1.5 只要求可改名称）
3. 周视图是否采用小时时间轴，还是维持 7 列日卡？
4. 页面导航形式：左侧栏还是顶部标签？
5. 锁定状态下顶部控制栏是否保留“关闭”与“钉住”按钮？
6. 锁定状态下若处于置顶模式，是否自动解除置顶？
7. 是否需要“置顶 + 钉住”组合（投屏展示日程时置顶且不可交互）？
8. 临期区最多同时展示几条，超出后的滚动方式？
9. 月视图每格任务摘要最多展示几条（N 值）？
10. 任务页是否增加“按优先级”或“按日期”分区作为第三种模式？
11. 启动台分组的呈现形式（标签页 / 分区），以及条目过多时滚动还是翻页？
12. 启动台布局可配置范围：图标尺寸档位、是否显示名称、行列数。
