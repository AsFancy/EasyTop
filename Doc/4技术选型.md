## 1. 数据模型（草案）

### 1.1 Task

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| id | string | 唯一标识 |
| title | string | 必填 |
| date | date | 所属日期 |
| startTime | time? | 可选 |
| endTime | time? | 可选；有值时必须晚于开始时间 |
| priority | enum | high / medium / low |
| manualStatus | enum | notStarted / inProgress / completed，由用户设置 |
| completedAt | datetime? | 完成时间，由 manualStatus 变为 completed 时记录 |
| notes | string? | 备注 |
| category | string? | 类别，单值自定义文本，可为空 |
| createdAt / updatedAt | datetime | 时间戳 |

> 系统状态（即将到期 / 已延期）不落库，由 date、时间与当前时间实时推导，并按需求 5.1 覆盖 manualStatus 的显示。

### 1.2 ShortcutGroup / ShortcutItem

- Group：id、name、order。
- Item：id、groupId、type（app / file / folder / url）、name、linkFile、target、args?、workingDir?、iconRef?、order、runAsAdmin。
- linkFile：数据目录内生成的 `.lnk` / `.url` 文件名，作为条目本体；target 为解析出的目标。
- “失效”为运行时检测结果，不作为持久字段，只记录最后检测时间。

### 1.3 Settings

- 键值结构，覆盖外观、行为、日历、安全、数据相关配置；默认值随版本内置。

### 1.4 Security

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| passwordHash | string? | 加盐哈希；为空表示未启用锁定 |
| autoLockOnSessionLock | bool | 系统锁屏时自动锁定，默认开启 |
| locked | bool | 当前是否处于锁定状态，跨重启保持 |
| unlockFailCount | int | 连续失败次数，用于递增等待 |
| unlockBlockedUntil | datetime? | 等待解除时间 |

### 1.5 HolidayData

- year。
- entries：date、type（holiday / workday）、name。
- 农历与节气由算法生成，不存入节假日表。

## 2. 数据目录结构

| 条目 | 说明 |
| --- | --- |
| tasks | 任务数据文件，明文 JSON |
| shortcuts/ | 启动台 `.lnk` / `.url` 快捷方式文件与条目索引（明文） |
| settings | 设置文件，明文 JSON |
| security | 密码哈希与锁定状态，明文 JSON |
| holiday | 节假日数据表，明文 |
| version | 数据格式版本号，明文 |

- 整个文件夹可整体复制替换；替换后程序按 version 判断兼容性。
- 所有文件均可直接打开查看；手动修改后需满足格式要求，否则程序拒绝加载并提示。

## 3. 数据版本与兼容

- TD-3.1 启动时校验 `version`；低版本按迁移规则升级后加载。
- TD-3.2 文件损坏或版本不兼容时，保留原文件并给出可读说明，不清空、不覆盖（需求 4.6.5 / 4.6.7）。
- TD-3.3 数据版本号高于当前程序时的处理方式待定（见 5）。
- TD-3.4 数据写入采用临时文件 + 原子替换实现，异常退出不得留下半写文件（需求 NFR-6.2.1 / NFR-6.2.2）。

---

## 4. 数据层实现约束

- TD-4.1 所有数据文件为明文，加载时必须做结构与类型校验；非法部分拒绝加载并提示，不影响其他合法数据。
- TD-4.2 快捷方式项必须是系统标准的 `.lnk` / `.url` 文件，不自定义封装格式。
- TD-4.3 系统状态不落库，界面按当前时间实时推导（需求 5.1 / 5.6）。
- TD-4.4 密码只保存加盐哈希，不保存明文；哈希文件位于同一数据目录，随目录替换而替换。
- TD-4.5 删除、清空、重置需清理对应数据文件与快捷方式文件，不遗留孤儿索引。

## 5. 待定项

2. 桌面层挂件实现方案：壁纸层定位、焦点控制、任务栏隐藏。

4. 区域级鼠标穿透实现方案（对应风险 R-9 / R-10）。
5. Windows 10 最低支持版本（需求 NFR-6.3.1）。
6. 数据文件夹位置：安装目录 / 用户目录 / 允许用户自选。
7. 数据版本号高于当前程序时的处理与提示。
8. 节假日数据更新通道（若与需求第 8 章结论联动）。
